# Leader powers

Upgraded versions of each Leader's ability ([06-progression](../docs/functional/06-progression.md#leader-powers)): each one tuned with the AI soak to win about 10 points more often than the base ability (2026-11-20). Unlocked in Nibelheim from a player level, for Rhinegold. `name` is the original German name, the same in every language (`LEADER_<ID>_POWER<n>_NAME`).
